# Native known-motion temporal reconstruction

Status: implementation specification, not qualification evidence.

## Objective and boundary

Implement Task 7b of `../plans/2026-10-27-daxa-slang-production.md`: actual C++/Daxa/Slang stateful two-eye temporal reconstruction, with retained outputs consumed directly by View. Preserve the Vulkan-only production path, original camera RGB and original stereo disparity. The independent `benchmarks/temporal_known_motion_oracle.py` is the semantic reference; its reviewed 63-test float64 domain is not general float32 GPU qualification. Adaptive stereo, estimated motion, physical dynamic-scene quality and sustained live 720p60 remain required later gates, not claims of this stage.

## Public interfaces

New `include/stereoforge/daxa_temporal.hpp`, `src/daxa_temporal.cpp`, shared `ops/temporal.slang` and a thin Daxa entry wrapper. Follow existing Depth/View ownership and timing conventions.

- `DaxaTemporalConfig`: `unsigned slots=2`, `max_contributors=4`, `max_reuses=4`; `int64_t max_age_ns=200000000`; `float relative_depth_tolerance=0.03f`, `confidence_floor=0.05f`. Slots are 2–3; contributor capacity is 1–4; reuse bound positive; age nonnegative; finite tolerance nonnegative and confidence in [0,1]. Reject invalid configuration at setup.
- `DaxaTimedRigPose`: `std::array<double,16> world_from_rig` row-major rigid transform, `int64_t timestamp_ns`, `std::string_view clock_domain`. A borrowed domain is consumed synchronously; never retain its view. Pose is world-from-original-left, fully known translation and orientation. Timestamp/domain must exactly match current capture host-ingress timestamp/domain. Reject nonfinite, malformed homogeneous/rigid matrices and mismatched clocks before submission. Use the scalar oracle rigid checks: exact homogeneous bottom row and absolute 1e-10 orthonormal/determinant tolerance. Reject negative pose timestamps and capture ID or host-ingress time above INT64_MAX; only then compare signed pose time and subtract checked values. Reject empty/unknown/unspecified device and host-clock identities. Bound each identity string to the existing capture maximum 65536 bytes; reserve owned epoch storage at setup so epoch replacement cannot allocate in process. Unknown alignment is not converted implicitly.
- `DaxaTemporal(std::shared_ptr<DaxaFoundation>, DaxaDepthPipeline::Frame const& prototype, DaxaTemporalConfig={})`: cache configuration/calibration, not the prototype's capture/slot. Require same foundation and metric calibration/map association at setup.
- `Frame process(DaxaDepthPipeline::Frame const&, std::optional<DaxaTimedRigPose> const&)`: only raw measured Depth input is admitted; Temporal cannot be passed as fresh input. Fixed-size host checks and matrix composition only. No implicit wait, readback, image-sized CPU loops or per-frame allocation.
- `collect()`, `bool can_process()`, `reset()`: nonblocking collection/admission/reset. Explicit collect also reclaims shared-device deferred resources without waiting, including repeated failed-submit retries without a new upstream Depth enqueue. can_process is admission-only; callers collect before upstream capture/upload. Reset severs history/sequence state but never destroys retained or pending output resources.
- `Frame`: copy/move-safe retained owner/slot/generation/ticket; `wait()`, `ready()`, timing accessor following existing stages, `observations()` and ancestry descriptors. Use temporary-swap assignment so child dies before producer/context. No fused metric buffer is named disparity.

Extend `DaxaObservationFrame` with a read-only ancestry descriptor and `ancestry()` accessor. Descriptor kind `SingleMeasured` derives singleton ancestry from existing six metric planes; kind `BoundedContributors` exposes separate GPU buffers for four sorted int64 contributor IDs per pixel (pixel-major `[observation][4]`), uint32 count, int64 oldest age, uint32 reuse count and uint32 origin mask. Name the descriptor `DaxaObservationAncestryView`, kind enum `DaxaObservationAncestryKind { SingleMeasured, BoundedContributors }`, and sidecar enum `DaxaObservationAncestryPlane { ContributorIds, Count, OldestAgeNs, Reuse, OriginMask }`. Expose kind(), capacity(), buffer(plane), size_bytes(plane). SingleMeasured reports capacity1; buffer requests for nonexistent sidecars reject (consumers derive from original planes). Descriptor reports capacity and bytes. Closed producers only; no public arbitrary-buffer construction. Adapter retains actual Temporal owner/slot, original current RGB Depth lease, calibration, device, generation and actual completion. Existing raw Depth adapter remains allocation-free, with no extra GPU ancestry storage.

Add `DaxaView::Frame::source_observations()` returning its retained generic input. Existing virtual-view `owner` indexes that input's `[eye][y][x]` planes and ancestry. Consumers gather lineage using owner on GPU, retaining both View frame (owner lifetime) and common source lease. Preview-only owner UINT_MAX has no metric lineage. Do not copy full ancestry into every virtual output or change existing View arithmetic/SPIR-V merely to expose lineage.

## Calibration and geometry

Use current Depth `image(LeftSupport/RightSupport)`; do not widen common RGB contract for support. Cache current maps and original/rectified models. Extract setup-only `DaxaRectifiedGeometry::validate_map_association(std::array<std::span<const float>,4>) const` into generic calibration module. Preserve existing distortion evaluator, double operation order, float conversion and nearest-even 1/32-pixel phase association exactly. View calls the extracted gate; keep its ray/pose/preview arithmetic unchanged. Temporal has no View-library dependency. Changed maps/calibration owner or shape requires a new compatible stage; reject before mutating history.

Per-eye maps into the original-left rig: `A_L=R1^T`, `A_R=original.right_to_left*R2^T`. Previous-to-current is `inverse(A_eye)*inverse(world_from_rig_current)*world_from_rig_previous*A_eye`. Compose fixed matrices in double then cast final GPU transform to float; reject any nonfinite final float coefficient before submission. Evaluate inverse(A) as an actual fixed-size affine inverse cached at setup, not an assumed transpose: admitted calibration rotations have finite orthonormal tolerance. Check invertibility/finiteness. Validate each float-cast K is finite and cast fx/fy strictly positive before device allocation; reject double focal lengths that underflow to float zero. Preserve each eye's K; use axial rectified Z, positive finite projection, floor(pixel+0.5), target support and nearest Z. Resolve equal-Z winners by lowest source linear index. Actual Depth admission requires rectified left/right fx,fy,cy approximately equal; distinct cx, unequal original intrinsics, per-eye fx!=fy and valid unequal R1/R2 are supported. Arbitrary unequal rectified focal lengths may only qualify a separately labelled diagnostic geometry harness.

## Frozen temporal semantics

Six metric planes retain selected source identity and selected observation age. Additional ancestry stores up to four complete sorted unique IDs, count, oldest contributor age, reuse count, OR of `1 << original_provenance`. Invalid six-plane defaults are canonical NaN 0x7fc00000/conf0/valid0/prov0/id-1/age0; invalid sidecar IDs -1 and all other fields0.

Fresh valid raw observations have provenance1 or5, one ancestor equal to selected ID, oldest age equal selected age and reuse0. Native trusted closed Depth contents are not host-scanned per frame. Source identity/order/clock/motion validation is transactional on the host. Diagnostic malformed-plane cases must not be silently accepted as independent fresh history.

History warp increments reuse and adds elapsed host-ingress nanoseconds to selected and oldest ages. Reject sample on signed64 overflow, oldest age above limit, reuse above limit, invalid support, invalid Z or confidence below floor. Preserve source identities/origin masks. Four reuses and exact age limit are inclusive. Compare prior reuse >= configured cap before incrementing, so UINT_MAX configuration cannot wrap. Eligibility never creates confidence.

Current valid geometry wins incompatible surfaces. Missing current can fill from eligible history: provenance1 becomes REPROJECTED2, derived5 and FUSED3 remain distinguishable; selected ID/age stays historical. This is aged evidence, not proof of visibility against a new dynamic occluder. Both valid and consistent (`abs(z-currentZ)<=tolerance*currentZ` as frozen oracle), with both confidences >= floor, may fuse only disjoint complete ancestry and union <= configured capacity. Otherwise keep current unchanged. Use stable positive confidence-weighted convex depth, max confidence, FUSED3, selected current ID/age, max oldest age and max reuse. Native numerical domain is explicitly float32 normal positive depth: current/history subnormal depths and transformed subnormal Z are canonical-invalid (before visibility competition) and counted as domain-rejected samples, not silently treated as CPU-oracle transaction exceptions. This deliberate native domain restriction requires separate diagnostic boundary tests and a disclosed normal-domain adapter for scalar expectations; the frozen float64 oracle remains unchanged. Guard confidence sum >0 even when configured floor=0. Evaluate positive convex depth in float32 and explicitly bound final rounded result to [low,high]; this is a documented native rounding policy, not exact general float64 equivalence. Unexpected NaN arithmetic preserves current rather than promoting a fused result, increments a diagnostic arithmetic-fault counter and fails qualification if nonzero on supported normal-domain cases. Current support invalidation precedes current domain counting (unsupported fresh pixels do not count as domain rejects). Counters distinguish fresh_domain_rejected, history_input_domain_rejected, projected_domain_rejected (once per source candidate, not duplicated across visibility passes), and arithmetic_faults. Projection nonfinite/nonpositive results reject only that history candidate, as in the reference. No epsilon masks discrete errors; exact rational fixtures and broader float differences are reported separately.

Missing pose produces current-only output and severs history. First recovered pose seeds history; next compatible pair may warp. Reject duplicate/late timestamp or capture ID within epoch without changing accepted history. Device/clock epoch change resets ordering; calibration/device incompatibility still rejects/new stage as appropriate. Explicit reset permits a new world origin. Excessive time gap yields current-only reseeding. Failure before or during submit never promotes partial output or changes accepted pose/history.

## Bounded resource and completion design

Use persistent Temporal output slots as history storage too. No duplicate full history buffers and no internal retained Temporal Frame: owner -> Frame -> owner would cycle. Impl owns `vector<shared_ptr<Slot>>` and a single `shared_ptr<Slot> history`. Output never overwrites active history.

Each Slot has six outputs, ancestry, immutable binding nodes, graph/query/parameter storage, generation, last write ticket and last read ticket. A candidate is reusable only if not active history, no external leases, and both tickets completed. Active history has TWO internal references (ring and history); ordinary slots have one. Account explicitly, not blindly `use_count()==1`.

When submission reads history, advance that history's last-read ticket to the actual new submit. Also retain candidate write ticket and input leases on partial-submit exceptions; failed output is not history. Same-queue shader write-to-read barriers are mandatory; bookkeeping alone is not memory visibility. Release candidate failed input only after all actual work completes.

History reprojection needs only Temporal-owned metric/ancestry buffers and cached scalar pose/time/identity. Once output write completes and external Temporal/common leases are gone, release that slot's upstream Depth/RGB capture even if it remains active history. Never manufacture a new outward frame from such history-only storage. Existing external leases retain current RGB until consumer completion/release. Store prior pose/time/clock independently of upstream borrowed pointers. Collection must not recursively retain past Frames, stale captures or an unbounded chain. Two slots intentionally backpressure when an old output remains externally retained; reject before upstream upload and recover on release.

Use bounded scratch Z and owner for two-eye projection: clear, Z splat, owner tie-break, gather/fuse writing all output planes. Persistent support inputs are current raw Depth; historical support is encoded by prior valid outputs. No device wait, full-frame readback or taskgraph rebuild inside process. Explicit diagnostic export is a separately timed boundary. Requested memory includes all slots/scratch/maps/readbacks actually allocated; initial combined Depth+Temporal+View target <=2GiB requested. Peak driver/process memory remains separate until measured.

## Verification and acceptance

Independent timed-world-point fixtures, not production self-comparison, cover identity, translation, moving rotation, per-eye calibrated poses, nearest/ties, holes/support, foreground incompatibility, confidence, provenance5, shared/capped lineage, selected-vs-oldest age, exact reuse/age limits, age overflow, missing/recovered pose, sequence/clock/reset failures and ring pressure. Verify all six planes plus complete sidecars; View owner-to-lineage gathering and preview invalid lineage. Diagnostic synthetic overrides happen only after actual Depth completion in a separate test executable, never production fixture flags or mutable public buffers.

Run functional independent review and separate performance refinement before root GPU. Performance probes execute actual hotpath with instrumented mock driver and reject new allocation/waits/readbacks; distinguish mock enqueue overhead from GPU performance. GPU root runs core and synchronization validation through teardown, frozen exact fixtures, retained/facade destruction tests and >=300-frame bounded stress. Primary benchmark disables RGB View; measure View increment separately. Actual SGM output and unique capture metadata over repeated synthetic pixels are explicitly static-content, not unique physical frames/live throughput. Freeze sources/compiler/binaries/SPIR-V and bind comparator inputs/results. Publish only after scoped checks pass; full project goal remains open.
